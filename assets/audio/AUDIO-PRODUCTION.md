# 오리지널 사운드 제작 기록

3차 품질 개선에서 만든 프로젝트 전용 음원입니다. 제3자 음원 다운로드, 상용 게임 복제, 외부 샘플 사용은 없습니다.

## 제작 방식

32kHz / 16bit PCM WAV. 음악은 스테레오, 짧은 효과음은 모노입니다.

던전/골렘 곡은 88 BPM, 24마디, 약 65.45초입니다. D 단조 계열의 온화한 화성과 여러 악구를 사용하고, 제한된 플루트 선율·하프 아르페지오·부드러운 현악 배경을 조합했습니다. 골렘은 동일한 음악 어법에 저음과 타악기를 보강합니다. 루프 꼬리는 원형 잔향으로 다음 시작 부분에 연결합니다. 끝에서 시작으로 넘어갈 때 샘플 불연속은 0.005 미만입니다.

검 휘두름은 필터링한 잡음의 빠른 포락선과 약한 금속 공명을 사용합니다. 타격은 낮은 충격, 고역 접촉음, 여러 금속 공명을 별도로 혼합합니다. 각각 3개의 자산으로 반복감을 줄입니다. 마법과 방패도 잡음·공명·충격을 조합하고 파일 앞뒤를 짧게 페이드합니다.

이는 실제 오케스트라나 무기 녹음이라고 주장하는 자산이 아니라, 프로젝트에서 합성·편곡한 오리지널 음원입니다. 실제 더빙은 포함하지 않습니다.

## 상대 음량

파일의 최대 샘플은 0.70 이하입니다. 음악 최대값은 0.62이고 실제 입력 믹스는 채널 음량 × 0.52입니다. 전투 믹스는 채널 음량 × 0.92입니다.

주요 효과음 내부 이득: 휘두름 0.27, 검 타격 0.43, 폭발 0.50, 방패 충돌 0.38, 파괴 0.32, 특수 방어 0.44. 실제 출력에는 사용자 효과음 음량과 압축기가 추가 적용됩니다. C/B/A/S 검 타격 계수는 0.72/0.86/1/1입니다.

교실 스피커의 물리적 음량은 소프트웨어 검사로 판단하지 않습니다. 설치된 스피커에서 사용자 음량 설정으로 최종 조정하세요.

## 재현·교체

AudioManager의 AudioAssets에서 자산 이름과 재생 역할을 확인할 수 있습니다. 같은 파일을 교체해도 전투 규칙을 수정할 필요가 없습니다.

generate.py는 제작용 소스입니다. 재생에는 Python이나 NumPy가 필요 없습니다. 제작을 다시 실행하려면 NumPy가 설치된 Python으로 이 파일을 실행하세요. audio-analysis.json에는 길이, 최대값, RMS 측정이 있습니다.
